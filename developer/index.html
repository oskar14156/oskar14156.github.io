Travel · iOS · Native Swift

Voyeva

Plan trips together, split expenses, ask the AI what fits into a free afternoon, and get a recap of the whole journey.

  • SwiftUI, around 85,000 lines, plus a widget extension, a share extension and a macOS target
  • Firebase Auth (Apple and Google sign-in), Firestore, Cloud Functions, Storage and FCM push
  • A trip assistant on Gemini through a Cloud Function: it reads the itinerary and proposes changes you can apply
  • Shared expenses with settle-up suggestions, and a spending analysis per category and person
  • Photos from the camera roll matched to the right trip day and pinned on the route
  • SwiftUI
  • Firebase
  • Gemini
  • MapKit
  • WidgetKit
  • RevenueCat

Fitness · iOS + watchOS · Native Swift

Novus

Gym and running in one place: plans, a training log, nutrition, supplements, routes on the map, and a coach that reads all of it.

  • SwiftUI and Core Data, around 72,000 lines, with a watchOS companion over WatchConnectivity
  • Runs and rides from HealthKit on a map, with pace, heart rate and elevation along the route
  • A year of training as a heatmap, muscle maps per session, Live Activities, widgets and Swift Charts
  • AI coach on Gemini through a Cloud Function: it reads training summaries, never raw Health data, and only after an explicit consent screen
  • SwiftUI

Finance · iOS + Android · React Native

Stub

Point the camera at any receipt, or drop in photos and PDF invoices, several at once. Stub reads every line item and shows where the money went.

  • The system document scanner finds the edges and straightens the paper; a queue analyses many receipts in the background
  • On-device text recognition through a custom native module: Vision in Swift, a Kotlin implementation on Android
  • Expo Router, Zustand and expo-sqlite; charts drawn with Skia
  • The largest Jest suite of my RN apps, covering the parsing and money logic
  • Expo SDK 57

Wellbeing · iOS · React Native

Unscroll

Blocks the apps you choose, shows your real screen time and what it adds up to over a lifetime.

  • The UI is React Native, but blocking needs Apple's Screen Time APIs, which only exist in Swift
  • Native module on FamilyControls, ManagedSettings and DeviceActivity, plus a WidgetKit widget
  • Five app extensions live in the Expo project: activity monitor, shield configuration, shield action, usage report and widget

Alarm · iOS + Android · React Native Live on Google Play

RiseProof

An alarm that only stops once you prove you're awake: push-ups counted by the camera, a photo of your made bed, or a brain game.

  • Alarms have to ring when the app is closed, so they run natively: AlarmKit and App Intents in Swift; on Android a ring service and boot-reschedule receivers in Kotlin
  • Push-ups and the photo task are checked on-device with Vision
  • Sentry with source maps for crash reports; RevenueCat for subscriptions on both stores
  • Config plugins for privacy manifest, localized permission strings and Android signing

How I ship an app.

Builds & releases

EAS Build profiles for dev client, internal QA and production, EAS Submit, signing credentials, TestFlight and Play internal testing tracks, versioning.

Native when needed

Expo Modules API in Swift and Kotlin, custom config plugins, and the CocoaPods and Gradle debugging that comes with them.

Quality

Jest for business logic, XCTest and UI tests on native iOS, Sentry for crashes and source maps, a written QA checklist before every release.

Backend

Firebase Auth, Firestore, Cloud Functions, Storage and Cloud Messaging; REST APIs; RevenueCat for subscriptions on both stores.

Teamwork

Feature branches, pull requests and reviews with another developer on shared apps. Git history and docs written so someone else can take over.

AI

Gemini behind Cloud Functions with consent and quotas, on-device models with Core ML and Vision, and agentic coding tools in my daily workflow.
