How it's built

Next.js 16 · React 19
App Router, server actions and a typed API layer, in TypeScript throughout
Store APIs
App Store Connect API, Google Android Publisher API, RevenueCat API v2, Huawei token exchange
Safety first
Every write is a dry run first, approved by typing an exact phrase; live writes are off unless the server allows them
Secrets
Store keys in an AES-256-GCM vault with local or cloud KMS, scoped per app and organisation
Drizzle · Postgres
Multi-tenant data with background jobs for status sweeps, reviews and notifications
593 tests
Unit tests, a local smoke test against every API route and a browser QA that screenshots every page in both themes
